# Librería Josué 1:9

Sitio de la librería y papelería de Cochabamba, en Av. América, entre Gabriel René Moreno y Enrique Finot.

Cada push a `main` publica el sitio en GitHub Pages:

https://ismadavidaa.github.io/libreria-josue/

## Qué editar

- Textos, teléfonos y secciones: `index.html`
- Horario que calcula si está abierto: `script.js` (`schedule`)
- Colores y diseño: `styles.css`

El horario visible también está en las tablas de `index.html`. Si cambia, hay que actualizar los dos lugares.
